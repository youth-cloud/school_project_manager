# 学校实训管理平台：奖学金申请材料

## 100字项目介绍

项目面向校园实训，已完成云端部署，支持学生、教师与管理员协作，覆盖选题组队、阶段提交、周报评审、答辩评分全流程。采用前后端分离架构，实现权限控制与成果归档，让实训管理更规范、过程可追溯，展现实践能力。

字数：100字符，含标点，不含标题及换行。

已遍历项目文件目录，并重点核对说明文档、前后端依赖、前端路由与工作台、后端认证权限及建组逻辑、业务实体、数据库表结构和部署配置。

school_project_manager/

│  ├─ src/views/                   22个页面目录（含登录、首页、个人信息）
│  ├─ src/api/                     各业务模块接口封装
│  ├─ src/layouts/                 平台布局与菜单

│  ├─ src/composables/             可复用组合逻辑
│  ├─ src/utils/                   请求、令牌与显示工具
│  └─ nginx.conf、Dockerfile       前端部署配置
├─ backend/                        Spring Boot 4后端
│  ├─ src/main/java/org/example/backend/

前端以页面、API、路由和状态管理组织；后端按认证、系统、教学业务分模块，包含Controller、Service、Mapper、Entity及DTO/VO等结构。部分业务校验、权限和事务处理集中在Controller中。数据采用MySQL保存，Redis用于令牌版本和黑名单等状态，成果附件保存到服务器文件目录。

## 面向评委的三个重点

1. 实际问题：将分散的课题、材料、周报、审核反馈与成绩统一管理。
2. 业务完整性：涵盖选题、建组、任务、提交、审核、答辩和成绩，支持学生、教师、管理员协作。
3. 工程落地：具备前后端分离、角色及业务数据权限、容器化部署配置和自动构建检查；云端部署情况依据项目作者提供的信息。
